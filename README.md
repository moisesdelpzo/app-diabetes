# Dulce Equilibrio 🌿

App web gratuita para personas con diabetes tipo 1 y tipo 2: recetas con carbohidratos por porción, ejercicios sencillos, consejos y un registro de glucosa con gráfica.

- Funciona en el navegador del celular y se puede instalar en la pantalla de inicio.
- Funciona sin internet una vez abierta.
- Los datos de glucosa se guardan solo en el dispositivo de cada persona.

> **Aviso:** información educativa general. No da diagnósticos ni calcula dosis de medicamentos, y no reemplaza la atención médica.
